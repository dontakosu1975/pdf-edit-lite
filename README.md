# PDF Edit Lite

ブラウザだけで動く、軽量なPDF文字編集MVPです。PDFを読み込み、ページ上に文字ボックスを追加・移動・削除して、編集済みPDFを書き出せます。

## 今できること

- PDFの読み込みとページ移動
- ズーム
- 任意ページへの文字ボックス追加
- 文字内容、サイズ、色の編集
- ドラッグによる位置調整
- 日本語フォント（TTF/OTF）の読み込みと埋め込み
- 編集済みPDFのダウンロード
- 「営業名・社名・原稿No」のクイック配置（任意機能）

## 起動

```bash
npm install
npm run dev
```

ブラウザで表示されたURLを開いてください。PDF処理はブラウザ内で行われ、PDFファイルはサーバーへ送信されません。

## 現在の設計上の注意

このMVPはPDF内部の既存文字を直接編集するのではなく、元の文字を白い矩形で覆い、その上に編集文字を重ねる方式です。位置を合わせやすく、元PDFのレイアウトを壊しにくい一方、背景が白以外の箇所では今後の改善が必要です。

次の候補は、選択範囲のリサイズ、背景色のスポイト、元PDF文字の検索・置換、編集履歴、PWA化です。
